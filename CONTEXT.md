# Sojusan Website

The single-page personal introduction site at sojusan.pl. It presents Sojusan and points visitors to their projects and YouTube channel.

## Language

**Sojusan**:
The creator's public brand and handle. The site introduces them by full name with the handle in quotes: Rafał "Sojusan" Grzegorczyk.
_Avoid_: the author, the owner

**Channel**:
Sojusan's YouTube channel of full gameplay videos with spoken commentary.
_Avoid_: Vlog, stream, account

**Sojusan GameList**:
Sojusan's public web project at gamelist.sojusan.pl (hosted under the SojusanApps GitHub organization), presented on the site as a project card.
_Avoid_: gamelist (lowercase), Game list app, the tracker

**Project card**:
A self-contained block on the page presenting one project with screenshot, one-line pitch, tech tags and a visit link.
_Avoid_: Portfolio item, tile

**Featured video**:
The single Channel video shown on the page as a click-to-load thumbnail.
_Avoid_: Latest videos, video feed

**Language switch**:
The single header control that toggles the whole page between Polish and English. Polish is the default and is never auto-switched from browser settings.
_Avoid_: Translation page, locale redirect

**Primary audience**:
Channel viewers and gamelist users. Collaborators are secondary and reached through a plain email link.
_Avoid_: Recruiters, clients
